# 配信の音を大きくする（LOUD）

YouTube は、大きすぎる音を小さくして再生しますが、小さい音を大きくはしてくれません。LOUD は、配信の音を下げられないぎりぎりの大きさ（曲全体でおよそ −14 LUFS）まで上げます。

## 使い方

1. STREAM の INST と VOCAL で配信のバランスを決めます。MASTER は 0.0 dB のままにします。
2. オケを流して本番と同じように歌い、サビに入ったら `LEARN` を押します。表示が「STOP 秒数」に変わり、測り始めます。
3. サビが終わったらもう一度押します（押さなくても20秒で終わります）。覚えた量（例 `+4.3 dB`）が表示されます。
4. 歌うときは `LOUD ON`、話すときは `LOUD OFF` にします。
5. 強さを選びます。ふだんは `STREAM`、もっと大きくしたいときは `CD` です。

| 強さ | サビの大きさ | 向いているとき |
|---|---|---|
| STREAM | およそ −11.5 LUFS | ふだんの配信。アーカイブもこの大きさで残ります |
| CD | およそ −8 LUFS | 配信中に市販の CD くらいの迫力がほしいとき。アーカイブは YouTube が小さくするので、STREAM より平たく聞こえることがあります |

左の数字は、OBS に出ている今の大きさ（直近3秒）です。

## 表示の意味

- `TOO QUIET`: 音が小さすぎて測れませんでした。覚えた量は前のままです。オケを流してから、もう一度 `LEARN` を押してください。
- 数字がオレンジ: 音割れを防ぐ天井が、音の山を削りすぎています。たいていは MASTER を 0.0 dB より上げているのが原因です。MASTER を 0.0 dB に戻してください（ダブルクリックで戻ります）。

## 知っておくこと

- LOUD ON の間は、配信の音が −1 dBTP を超えないよう、天井が自動で山を削ります。大きくしたいときは MASTER ではなく `CD` を選んでください。
- 切り替えは0.5秒かけてなめらかに変わるので、曲の途中で押しても音が跳ねません。
- LOUD OFF のときは、音を一切変えません。覚えた量は残るので、次に ON にすれば同じだけ上がります。
- BGM と効果音は LOUD で大きくなりません。天井だけはかかります。
- LOUD の状態と覚えた量は、プロジェクトに保存されます。
