# ノイズ除去とエフェクト

## ノイズ除去（NR）

エアコンや PC のファンのように、ずっと同じように鳴っている雑音を、マイクの声から減らします。オケには影響しません。ON にしても、自分に返る声は遅れません。

1. `NR OFF` を押して `NR ON` にします。
2. つまみ（減らす量、0〜18 dB）を 3〜6 dB から試します。
3. 声を出さずに、いつものマイク位置で `LEARN` を押し、約1秒待ちます。`RELEARN` に変われば完了です。
4. 歌ってみて、裏声や語尾がやせるようなら、つまみを下げます。

`LEARN` の最中に声を出すと、声を雑音として覚えてしまいます。そのときは、黙ったまま `RELEARN` を押し直してください。マイクの位置や部屋を変えたときも押し直します。キーボードの音や人の話し声のように、不規則な音は減らせません。

## 声にエフェクトをかける（FX CHAIN）

1. FX CHAIN の行の `Scan` から「すべて検索し直す」を選び、Mac に入っているプラグインを探します（初回だけ）。
2. `+ VST` を押し、一覧から選んで「追加」を押します。
3. 追加されたボタンを押すと、そのプラグインの画面が開きます。

使える形式は VST3 と Audio Unit です。いくつでも並べられ、左から順にかかります。`B` で一時的に止め、`X` で外します。左端のつまみをドラッグすると、順番を入れ替えられます。

新しいプラグインを入れたときは、「フォルダを指定して追加で検索」を使うと、増えた分だけを数秒で読み込めます。検索の途中で止まって見えても、ファイル名の後ろの秒数が増えていれば正常です。最後まで待ってください。読めなかったファイルは、終わったときに一覧で表示します。

## 自分の返しだけエフェクトを薄くする（MON WET）

VOCAL MON 列の `MON WET` は、最後に並べたエフェクトを、自分のヘッドホンにどれだけ返すかを決めます。配信に乗る声は変わりません。配信ではリバーブを深くかけたいが、自分の耳では歌いにくい、というときに下げてください。エフェクトが2つ以上あり、最後がリバーブなどのときに効きます。

## 配信全体にかける（STREAM FX）

オケと声をまとめた配信の音全体にかけたいもの（仕上げのコンプやリミッターなど）は、STREAM FX の行に入れます。使い方は FX CHAIN と同じです。自分の返しと、BGM・効果音にはかかりません。
