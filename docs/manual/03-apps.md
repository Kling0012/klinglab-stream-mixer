# アプリの音を取り込む

カラオケ音源を流しているブラウザや音楽アプリの音を、ミキサーに直接取り込みます。仮想ケーブルはいりません。

1. 取り込みたいアプリで、先に音を再生しておきます。
2. INST INPUT の左の小欄が `APP` になっていることを確かめます。
3. 右の欄を押すと、アプリの一覧が出ます。取り込むアプリにチェックを入れて「適用」を押します。
4. INST INPUT のメーター（オレンジ）が動けば完了です。

最大8つのアプリを同時に選べ、選んだ音はまとめてオケとして扱います。Chrome のように画面ごとに別のプロセスで音を出すアプリも、一覧でアプリ名にチェックを入れれば全部まとめて取り込みます。

一度選んだアプリは覚えています。アプリを閉じて開き直しても、数秒で自動的につながり直します。

## 二重に聞こえないように

一覧の下にある「取り込んだアプリの音をスピーカーから消す」は、最初からオンになっています。オンにしておくと、取り込んでいる間はアプリの元の音が鳴らず、ミキサーを通った音だけが聞こえます。オフにすると、元の音もそのまま鳴ります。

## 一覧に出ないとき

そのアプリで一度音を鳴らしてから、一覧を開き直してください。音を出していないアプリには「[音声未検出]」と付きます。

何も取り込めない場合は、「システム設定 → プライバシーとセキュリティ → 画面収録とシステムオーディオ録音」で Klinglab Stream Mixer がオンになっているかを確かめてください。

## 仮想ケーブルで入れる場合

BlackHole などの仮想デバイスを使いたいときは、左の小欄を `CABLE` にして、右の欄でそのデバイスを選びます。同じ仮想デバイスを STREAM OUT にも選ぶと音がループするので、ミキサーは保存を止めて警告します。
