# 入出力を選ぶ

画面上部の欄で、音の入口と出口を選びます。必ず選ぶのは MIC INPUT と MONITOR OUT の2つです。

| 欄 | 選ぶもの |
|---|---|
| INST INPUT | オケの入口です。ふつうは左の小欄を `APP` にして、右の欄でアプリを選びます |
| MIC INPUT | 使っているマイクか、オーディオインターフェース |
| MONITOR OUT | 自分が聞くヘッドホン |
| STREAM OUT | OBS 以外のソフトにも配信の音を出したいときだけ選びます。ふだんは空欄で大丈夫です |
| MIC MON OUT | 声だけを Discord などに渡したいときに選びます（「声だけを通話に送る」を参照） |

OBS へは、専用のプラグインが音を直接受け取ります。そのため STREAM OUT を選ぶ必要はありません。

## 遅れの表示

右上の表示（例: `CoreAudio · 48k · 128smp · RT 9.8ms`）は、話してから自分の耳に返るまでの時間の目安です。12ms 以下なら緑、20ms までならオレンジ、それより長いと赤になります。

赤いときは `PANEL` を押し、バッファの大きさを1段ずつ小さくしてください。小さくしすぎると音がぷつぷつ途切れるので、途切れない範囲でいちばん小さい値にします。USB マイクより、オーディオインターフェースのほうが遅れは短くなります。
