# プロジェクトとショートカット

デバイス、音量、エフェクト、取り込むアプリ、ノイズ除去、LOUD の状態を「プロジェクト」として名前を付けて保存できます。「雑談」「歌枠」のように用途ごとに分けておくと便利です。

| ボタン | 動作 |
|---|---|
| 新規 | 今の設定のまま、名前のないプロジェクトとして始めます |
| 保存 | 上書き保存します。名前がまだなければ聞きます |
| 別名保存 | 別の名前で保存します |
| 削除 | 選んでいるプロジェクトを削除します（元に戻せません） |
| 1〜9登録 | 保存したプロジェクトを番号 1〜9 に割り当てます |

番号の割り当ては、すべてのプロジェクトで共通です。

## ショートカット

ミキサーが後ろに隠れていても効きます。

| キー | 動作 |
|---|---|
| ⌃⌥⇧ + 1〜9 | その番号のプロジェクトを呼び出す |
| ⌃⌥⇧ + F1〜F9 | FX CHAIN の左から何番目かのエフェクトを止める／戻す |

F キーは「何番目か」に効きます。エフェクトを並べ替えると、同じキーで切り替わる相手も変わります。

ボタンが「1〜9登録 !」になっているときは、ほかのアプリが同じキーを使っています。そのアプリを終了してから、ミキサーを開き直してください。

設定は `~/Library/Application Support/Klinglab Stream Mixer/` に保存されます。メニューの「設定フォルダを開く」から開けます。
