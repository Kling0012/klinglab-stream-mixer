# 画面の見かた

下半分に6つの列があります。

| 列 | 何の音量か |
|---|---|
| INST INPUT（オレンジ） | 取り込んだオケの入ってきた大きさを見る列です。フェーダーはありません。下にノイズ除去があります |
| INST MON（青） | 自分に聞こえるオケの音量 |
| STREAM（緑） | 視聴者に届く音量です。INST（オケ）と VOCAL（声）の2本で配信のバランスを決め、下の MASTER で配信全体を上げ下げします |
| VOCAL MON（紫） | 自分に聞こえる声の音量です。`MON` が黒いときに声が返ります |
| BGM（青緑） | BGM の、配信に乗る大きさ（STREAM）と自分に聞こえる大きさ（MON） |
| SE（ピンク） | 効果音の、配信に乗る大きさと自分に聞こえる大きさ |

自分に聞こえる音と、視聴者に届く音は別々です。たとえば INST MON を下げても、配信のオケの大きさは変わりません。「配信だとオケが小さい」と言われたら STREAM の INST を、配信全体が小さいときは MASTER を動かします。

## フェーダー

数字は dB です。0.0 dB が元の大きさで、−6.0 dB でおよそ半分になります。STREAM の INST・VOCAL・MASTER と、BGM・SE は +6.0 dB まで上げられます。自分への返し（INST MON・VOCAL MON）は 0.0 dB から下げる方向だけです。ダブルクリックすると 0.0 dB に戻ります。

大きくしたいときは、まず片方を下げてバランスを取り、それでも足りなければ MASTER を上げてください。

## メーター

目盛りは 0 から −60 dB まで、6 dB きざみです。バーは −6 dB まで列の色、−6〜0 dB で黄色、0 dB を超えると赤になります。赤い細い線は直近1.5秒でいちばん大きかった位置です。

上の丸いランプは、一度でも 0 dB に届くと赤く点いたままになります。メーターを押すと消えます。配信の前に消しておき、終わったあとで点いていなければ、音は割れていません。歌のいちばん大きいところで −6 dB 前後に収まるのが目安です。

## 声とオケのずれ

配信の音では、エフェクトで声が遅れた分だけ、オケを自動で遅らせてそろえています。録画を見てずれが気になったときだけ、STREAM の上にある `−` `+` で 5ms ずつ調整してください。自分の耳への返しは変わりません。

## 番号を表示する

⌥N を押すと、画面のボタンや文字に番号が出ます。問い合わせのときに「12番のボタン」のように伝えられます。もう一度押すと消えます。
