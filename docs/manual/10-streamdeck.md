# Stream Deck

専用のプラグインを入れると、Stream Deck のボタンにミキサーの本当の状態が表示されます。プロジェクトを呼び出したときや、画面で `B` を押したときも、ボタンの表示がすぐに変わります。

## 入れかた

メニューの「Stream Deck の使い方」にある「Stream Deck プラグインを追加」を押します。Stream Deck アプリで確認が出たら追加してください。右側の一覧に「Klinglab Stream Mixer」が増えるので、使いたい機能をボタンにドラッグし、番号を選びます。

| 機能 | 押すと | 表示 |
|---|---|---|
| FX On/Off | FX CHAIN の n 番目を止める／戻す | ON はオレンジのランプ |
| Project | n 番のプロジェクトを呼び出す | 呼び出し中は上にオレンジの帯 |
| STREAM FX On/Off | STREAM FX の n 番目を止める／戻す | ON は緑のランプ |
| BGM | n 番の BGM を再生／停止 | 再生中は青緑の帯 |
| SE | n 番の効果音を鳴らす／止める | 鳴っている間はピンクの帯 |
| Stop Sounds | BGM・効果音・両方を止める | 止める対象が鳴っている間はオレンジの帯 |
| LOUD On/Off | LOUD を切り替える | ON の間はオレンジの帯 |
| LOUD Learn | LEARN を始める／終える | 測っている間は緑の帯と残り秒数 |
| LOUD Mode | STREAM と CD を切り替える | 今の強さを表示 |

番号の下が「-」のときは、その番号に何も入っていません。ミキサーが起動していないと「MIXER OFF」と出ます。そのとき押しても何も起きず、操作がためられて後でまとめて実行されることもありません。
