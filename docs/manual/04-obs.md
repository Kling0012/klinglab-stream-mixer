# OBS に音を送る

インストーラーで、OBS 用のプラグインも入ります。

1. OBS を起動します。インストールの前から開いていた場合は、一度終了して開き直してください。
2. 「ソース」の「＋」を押し、「Klinglab Stream Mixer」を選んで追加します。
3. ミキサーで音を流し、OBS の音声ミキサーで「Klinglab Stream Mixer」のメーターが動けば完了です。

このソースに設定はありません。ミキサーが起動していない間は無音で、起動すると自動でつながります。起動の順番はどちらが先でもかまいません。

## 音が二重にならないように

- OBS の元の「マイク」はミュートします。声はミキサー経由で届いています。
- 「デスクトップ音声」は無効にするのがおすすめです（設定 → 音声）。
- 配信に音を出すのは「Klinglab Stream Mixer」ソース1本だけにします。

## ソースが一覧に出ないとき

OBS を開き直しても出ない場合は、インストーラーをもう一度実行してください。プラグインは `~/Library/Application Support/obs-studio/plugins/` に入ります。
