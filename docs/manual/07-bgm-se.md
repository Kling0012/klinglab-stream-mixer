# BGM と効果音

画面右上の上の欄が BGM、下の欄が効果音（SE）です。

## 入れる

Finder からファイルを欄にドラッグします。いくつかまとめてでもかまいません。使える形式は WAV・MP3・FLAC・OGG・AIFF・AAC（M4A）です。入れたファイルはミキサーの中にコピーされるので、元のファイルを動かしたり消したりしても鳴ります。効果音は3分までです。長い音は BGM の欄に入れてください。

BGM と効果音の一覧はすべてのプロジェクトで共通です。音量だけはプロジェクトごとに保存されます。

## 鳴らす・止める

- BGM: 押すと再生し、もう一度押すと止まります。一度に鳴るのは1曲で、別の曲を押すと1秒かけて入れ替わります。丸い矢印が光っている曲は、最後まで行くと頭に戻ります。`STOP` で1秒かけて止まります。
- 効果音: 押すと鳴り、鳴っている間にもう一度押すと止まります。いくつも重ねて鳴らせます。`STOP` で全部止まります。

## 名前を変える・並べ替える・外す

名前にマウスを乗せると鉛筆と × が出ます。鉛筆（または右クリック）で名前を変え、Enter で決定、Esc で取り消します。名前をドラッグすると並べ替えられ、左の番号も付け直されます。× を押すと、確認のあと一覧から外れます。

Stream Deck のボタンは番号で音を決めています。並べ替えると、同じボタンで別の音が鳴るので注意してください。

## 音量

BGM 列・SE 列の左のフェーダーが配信に乗る大きさ、右が自分に聞こえる大きさです。`MON` を消すと自分には聞こえなくなります。初期値は BGM が −6.0 dB、効果音が −3.1 dB です。
