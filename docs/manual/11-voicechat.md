# 声だけを通話に送る（MIC MON OUT）

Discord などの通話に、エフェクトのかかった声だけを送れます。オケやゲームの音、BGM は混ざりません。

1. 仮想オーディオデバイス（例: BlackHole 2ch）を入れます。
2. ミキサーの MIC MON OUT で、その仮想デバイスを選びます。右のつまみは 1.00 から始めます。
3. Discord の入力デバイスを、同じ仮想デバイスにします。
4. Discord の音声処理（ノイズ抑制、エコー除去、自動入力感度、自動音量調節）はすべて OFF にします。ON のままだと、リバーブの余韻やボイスチェンジャーの声が削られます。

通話相手の声も配信に乗せたいときは、INST INPUT のアプリ一覧で Discord も選んでください。相手の声はオケと同じ扱いになります。
